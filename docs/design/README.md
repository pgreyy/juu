# Juu design handoff

Put this whole folder in your project as `docs/design/`, then paste CLAUDE-CODE-PROMPT.md into Claude Code.

| File | What it is |
|---|---|
| CLAUDE-CODE-PROMPT.md | The one message to paste into Claude Code |
| juu-app-reference.html | The exact design. Open it in a browser and click around. Source of truth |
| juu-design-system.md | Colours, fonts, layout and rules written out |
| juu-landing-brief.md | The landing page plan for hallmark |
| juu-spec.md | Latest product spec |
| assets/juu-logo.svg, juu-logo-dark.svg, favicon.svg | Brand marks |
| assets/icons/ | The eight page icons + sidebar icon |
